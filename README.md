# number_counter

Counts the number of each adjacent digit in a number, before turning that into another number, re-counting, and continuing this process `n` times.

For example, if the starting number is `1` and `n = 5`, the program outputs:
- `1`
- `11` (one `1`)
- `21` (two `1`s)
- `1211` (one `2`, one `1`)
- `111221` (one `1`, one `2`, two `1`s)
- `312211` (three `1`s, two `2`s, one `1`)
